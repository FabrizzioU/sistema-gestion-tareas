# sistema-gestion-tareas

Aplicación desarrollada como actividad de trabajo colaborativo con GitHub



\# Gestor de Actividades Académicas



Proyecto individual desarrollado como actividad práctica de GitHub, simulando el flujo de trabajo colaborativo mediante ramas independientes.



\## Integrante

\- Tu Nombre Completo



\## Objetivo

Implementar una aplicación sencilla que permita registrar, visualizar y organizar actividades académicas, aplicando un flujo de trabajo profesional con Git y GitHub (ramas, Issues, Pull Requests, Code Review y resolución de conflictos).



\## Tecnologías

\- HTML

\- CSS

\- JavaScript



\## Instalación

1\. Clonar el repositorio.

2\. Abrir la carpeta.

3\. Ejecutar `index.html` en el navegador.



\## Funcionalidades

\- Registrar actividades (nombre, descripción, responsable, prioridad, estado).

\- Visualizar actividades registradas.
